# Roblox Up-and-Coming Forecast

Deterministic Node.js forecast for the make.fun Roblox Up-and-Coming top 10 bounty.

Run with Node 22 in the make.fun sandbox. Reads `task.json` and `history.ndjson` from `MAKEFUN_INPUT_DIR` (default `/input`) and writes the forecast to `MAKEFUN_OUTPUT_DIR` (default `/output`).
